# NumVerse - Code & Number Base Converter

A browser-based tool for converting numbers between Decimal, Binary, Octal, and Hexadecimal representations, featuring an interactive assistant for explanations and voice input.

## Features

- **Multi-Base Conversion**: Convert seamlessly between:
  - Decimal (Base 10)
  - Binary (Base 2)
  - Octal (Base 8)
  - Hexadecimal (Base 16)
- **Fractional Support**: Handles numbers with decimal points across bases.
- **Interactive Assistant**: Built-in chatbot providing step-by-step conversion logic and number system theory.
- **Voice Input**: Speech-to-text input support (Google Chrome).

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
